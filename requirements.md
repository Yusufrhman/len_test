# Requirements

## Overview

Build an application to display and manage entities that contain geographical location information.

An entity may represent various types of real-world objects, such as:
- Vehicles
- IoT devices
- Facility locations
- Other objects with geographic coordinates

Each entity must have:
- Identity
- Basic attributes
- Status
- Geographic location information in the form of coordinates

## Technology Requirements

The application must consist of:

### Frontend
- React
- TypeScript

### Backend
- Go

### Data
- Data must be able to be stored and retrieved through the backend.

## Functional Requirements

### Map

- [ ] Display entities on a map.
- [ ] Add entities to the map.
- [ ] Delete entities from the map.
- [ ] Update entities on the map.
- [ ] View entity details on the map.

### Validation

- [ ] Frontend must validate input/data.
- [ ] Backend must validate input/data.

## Technical Decisions

The candidate is free to choose:

- [ ] Libraries
- [ ] Database
- [ ] API design
- [ ] State management
- [ ] Map provider / map library
- [ ] Styling approach

## Documentation Requirements

The repository documentation must include:

- [ ] Instructions for running the application.
- [ ] Reasons for choosing the libraries used.
- [ ] Explanation of the Agentic AI workflow and how extensively it was used during the development of the test.
- [ ] Explanation of any unfinished features.

## Submission Requirements

- [ ] Submit a Git repository containing the application source code and documentation.
- [ ] Document any features that are not completed.
- [ ] If Agentic AI is used, include an `AGENT.md` or `CLAUDE.md` file in the Git repository.
